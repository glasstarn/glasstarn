# Documentation

| Guide | Use it when |
|---|---|
| [Demo projects](demos.md) | You want to try the product on invented data, with a problem planted in each |
| [Five-minute demo](demo-bpic2019.md) | You want to see the product on a real company's purchasing log first |
| [Getting started](getting-started.md) | You want to run the browser or CLI and analyze a first log |
| [Headless agents](headless-agents.md) | You want an approved agent harness to prepare, analyze, query, and save a project without a browser |
| [Connected extracts](connectors.md) | You want approved SaaS records downloaded directly into local project files |
| [Connected preparation](connected-preparation.md) | You want linked relational tables turned into a native OCEL log |
| [Process packs](process-packs.md) | Your data is a system export (SAP, Oracle, Dynamics, Salesforce and others) |
| [Preparation recipes](preparation-recipes.md) | You want an agent to construct and validate an event log from approved CSV extracts |
| [Architecture](architecture.md) | You want to understand the executable, engine, and runtime boundaries |
| [Data and projects](data-and-projects.md) | You are preparing columns, interpretation decisions, or a reproducible project |
| [Process-mining methods](process-mining.md) | You need to choose or correctly interpret an analysis |
| [Object-centric mining](object-centric.md) | One event relates to several business objects |
| [Agent access](agent-access.md) | You want Codex, Claude, or another MCP client to investigate results |
| [Trademarks and compatibility](trademarks.md) | You want to know what "tested" means for a pack, and who owns the product names |
