## What "tested" means

A pack marked **tested** was run by the Glasstarn project on a real or trial
system of that product: its data check and build passed, and selected items
were compared with the history shown by the system itself. Its README says
which release was used and what was and was not covered. It is not a vendor
certification, and other releases, configurations and custom fields may
differ. A pack marked **untested** was written from the vendor's public
documentation and checked only on made-up data in the standard layout.
